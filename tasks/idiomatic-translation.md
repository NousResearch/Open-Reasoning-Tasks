# Idiomatic Translation

## Description:
This task involves translating text across languages while preserving meaning, cultural context, and intent. It evaluates the model’s ability to adapt idioms, metaphors, and domain-specific language into equivalent expressions that resonate with the target audience.

## Modality:
Text

## Examples:

### Example 1:

Input:

```
Spanish: “Está lloviendo a cántaros.”
```

Output:

```
Literal translation: "It's raining pitchers."
“It’s raining heavily.”
```

---

### Example 2:

Input:

```
French: “Il a le cafard.”
```

Output:

```
Literal translation: “He has the cockroach.”
Context: French idiom meaning someone feels down or depressed.
“He’s feeling blue.”
```

---

### Example 3:

Input:

```
German: “Er hat die Nase voll.”
```

Output:

```
Literal translation: “He has the nose full.”
Context: German idiom indicating frustration or being fed up.
“He’s had it up to here.”
```
